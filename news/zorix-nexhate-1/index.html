Preparing Zorix NexHate 1 for release

Moving our first-generation translation AI model from preview evaluation toward release, with a focus on preserving meaning, tone, and context.

Explore Zorix Translate View current comparison

Zorix is preparing NexHate 1, the first named generation of the NexHate translation AI family, for release. The goal is straightforward: translation should preserve what a person means, how they say it, and the context surrounding the text—not only replace words from one language with words from another.

Why NexHate

Translation is more than matching words

Many translation tasks are easy when a sentence is isolated and literal. They become harder when the important information lives in tone, ambiguity, previous sentences, formatting, or the relationship between multiple parts of a conversation.

NexHate is Zorix's translation-specific model family. NexHate 1 is being developed around the idea that translation quality depends on preserving meaning, tone, and context together.

This is also why Zorix is treating NexHate as a dedicated model family rather than as a translation mode layered on top of an unrelated general-purpose model.

From preview to generation one

Moving the xhigh preview toward NexHate 1

Zorix first announced the NexHate project on August 22. The model entered Early Access on August 30, and the current Zorix Translate snapshot tracks the model as Zorix NexHate 1 Preview (xhigh).

That preview remains a preview measurement—not the final release specification. The next step is to move from the preview identity toward NexHate 1 as the first-generation release of the family.

Current state

Preview today. First generation next.

Zorix is keeping the Preview designation while release qualification continues. Final release timing, final specifications, pricing, and complete access details are not announced in this note.

Release preparation

Preparing the first release

NexHate 1 is now being prepared as the first generation of Zorix's translation AI model family. During this stage, the preview label remains useful: it separates measurements collected during preview operation from the eventual release identity.

Zorix is not treating the current preview score, request volume, or xhigh profile name as a promise that every final release configuration will be identical. When the release is ready, the model should be evaluated as the released configuration, not retroactively assumed to be identical to the preview.

The focus of this announcement is therefore the transition itself: NexHate is moving from an experimental and Early Access translation project toward its first named generation.

Access and availability

Release details will follow

This announcement does not set a final launch date or publish final pricing, architecture, parameter count, context length, or complete availability policy for NexHate 1.

The current preview remains represented in Zorix Translate as NexHate 1 Preview (xhigh), where its published score and request measurement can be compared with the currently selected translation reference model.

Looking ahead

A dedicated translation model family

NexHate 1 represents a new model category inside Zorix: a system whose primary job is translation. The first release is intended to establish the foundation for that family before later generations expand it further.

More information will be published when Zorix is ready to describe the released configuration rather than the preview configuration.
