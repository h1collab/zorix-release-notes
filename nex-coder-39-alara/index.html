Introducing Alara

A model preview centered on software work.

Nex Coder 3.9 Alara is the next model preview in the Nex Coder 3.9 family. The current evaluation is broader than code completion alone: it includes long-horizon software engineering, terminal work, tool use, computer interaction, browser research, mathematics, and scientific reasoning.

This page reports Alara as an internal Zorix preview. The benchmark figures below are not independent third-party verification, and they should not be read as a public release claim.

Software engineering

Built around complete engineering tasks.

The Alara preview is being evaluated on tasks that require more than producing an isolated code snippet. The current suite includes terminal-based engineering, repository work, multi-step implementation, debugging, verification, and benchmark tasks where a working result matters.

Agentic work

Longer workflows, tools, and execution.

Alara is also being tested in settings where the model must plan, use tools, execute steps, inspect outcomes, and continue from intermediate results. Terminal-Bench, DeepSWE, FrontierCode, and the Coding Agent Index are included to study this behavior under different evaluation harnesses.

Computer interaction

Beyond the editor.

The preview extends into computer and interface interaction through evaluations such as Agents' Last Exam, OSWorld, ScreenSpot-Pro, and AutomationBench. These results are reported separately from coding scores because each benchmark measures a different capability and uses its own scoring definition.

Research and reasoning

A wider evaluation surface.

Alara's current evaluation set also includes web research, mathematics, and science-oriented benchmarks. These measurements are part of the preview process; they do not imply that every benchmark measures the same underlying skill or can be combined into a universal score.

How results are reported

Public references. Alara Ultra. Native units.

Each external comparison uses a listed public reference endpoint. Alara shows only the Ultra internal preview result. Low, Medium, High, XHigh, and Max are intentionally not published on this page.

Scores remain in each benchmark's native units. We do not convert benchmark scores into request counts, token usage, or community voting scores.

Availability

Internal preview.

Nex Coder 3.9 Alara is currently listed by Zorix as an internal preview. Public product availability, API access, pricing, context limits, and a general release schedule are not announced on this page.
