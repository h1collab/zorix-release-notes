Score it the way the benchmark scores it.

The earlier Alara concept normalized almost everything into a single 0–100 visual scale. That makes cross-benchmark graphics easy to read, but it is not how frontier evaluation pages actually report results. This revision keeps each benchmark’s native definition: resolution rate for Terminal-Bench Science, weighted rubric score for FrontierCode, success rate for OSWorld, overall accuracy for BFCL, and a composite pass@1 index for Artificial Analysis.

For public comparisons, the page now uses published endpoints rather than inventing full competitor effort curves. Alara alone shows a Ultra internal preview. On non-saturated benchmarks with enough remaining headroom, Ultra is targeted roughly 10–14 raw score points above the strongest public reference. When the public benchmark is already above roughly 90–95%, the raw gap is ceiling-limited and is not forced.

How the public runs are actually scored

Terminal-Bench / Science

Resolution rate over verifiable terminal tasks. Science leaderboard also exposes confidence interval, tokens and total cost by model + agent harness.

FrontierCode 1.1

Weighted rubric score with blocker criteria. A solution that fails blocking requirements receives zero; the board plots score against rollout cost and reasoning effort.

Artificial Analysis Coding Agent Index

Three attempts per task, task-normalized pass@1, then equal weighting across DeepSWE, Terminal-Bench v2.1 and SWE-Atlas-QnA.

OSWorld Verified

Success rate under unified computer environments and disclosed agent settings / max steps; verified trajectories support reproducibility.

BFCL V4

Overall accuracy built from agentic, multi-turn, live/non-live function calling and hallucination-related components.

SWE-bench

Reports percent resolved. For like-for-like model comparison, the same agent harness matters as much as the model name.
