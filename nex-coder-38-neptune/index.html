Made for Nex Coder 3.8 Preview — Neptune

We’re introducing Nex Coder 3.8 Preview — Neptune, the depth-oriented profile of the AA4 / Zorix4 generation for repository-scale software engineering.

Neptune is designed for difficult coding work that spans files, tools, execution environments, and long chains of decisions. Its focus is not simply producing the next plausible patch; it is maintaining enough context to understand a system, plan changes, execute them with tools, and verify the result.

The current preview profile publishes a 2 million token context window. Its parameter count remains undisclosed, and the current Zorix model catalog describes the architecture as Closed / AA4.

Neptune is in preview. Availability can differ between accounts while staged rollout is active. The figures on this page describe the published Zorix preview profile and should not be read as a guarantee that every Code account can select Neptune at the same time.

    Repository-scale engineering

    Difficult software work is rarely contained in one file or one turn. A change may begin in an issue, cross several modules, alter a configuration boundary, require a migration, and only become trustworthy after tests and runtime behavior agree.

    Neptune’s depth-oriented profile is designed around this larger unit of work.

    01
    Long-context repository understanding
    Use the published 2M context window to retain more code, configuration, documentation, and task state while reasoning across a repository.
    02
    Adaptive planning
    Build a plan from the evidence available, then revise it when commands, tests, diffs, or new files reveal that the original assumptions were wrong.
    03
    Tool use inside the reasoning loop
    Treat search, code inspection, command execution, tests, and other tools as part of the engineering loop rather than as a final step after reasoning.
    04
    Verification-heavy completion
    Continue past the first plausible implementation. Use evidence from the environment to decide whether a change is actually complete.
